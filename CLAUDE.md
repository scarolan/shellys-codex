# Shelly's Codex

A collection of interactive fiction games written in Inform 6, served as a GitHub Pages site via Parchment.

## Repo layout

- `index.html` — landing page that lists all stories with links
- Each story gets its own directory (e.g., `neon-shadows/`):
  - `*.inf` — Inform 6 source code (the ONLY file to edit for story changes)
  - `*.z5` — compiled Z-machine story file (generated by the compiler)
  - `index.html` — Parchment interpreter configured to load the story
  - `test_*.sh` — bash test harness using dfrotz
  - `CLAUDE.md` — game-specific documentation

## Tech stack

- **Language:** Inform 6 compiler (`inform6`), Z-machine interpreter (`dfrotz`)
- **Inform 6 library:** `/usr/local/share/inform6/lib/`
- **Browser player:** Parchment (single-file distribution, configured per story)
- **Hosting:** GitHub Pages from `main` branch

## Compiling

```bash
cd neon-shadows
inform6 +/usr/local/share/inform6/lib/ neon_shadows.inf neon_shadows.z5
```

Always recompile after editing `.inf` files. The `.z5` must be committed alongside the source.

## Testing

```bash
cd neon-shadows && bash test_neon_shadows.sh
```

Tests compile the game, then pipe commands into dfrotz and grep output for expected strings.

## Conventions

- Each story is self-contained in its own directory
- The compiled `.z5` file is always committed (needed for GitHub Pages)
- Tests must pass before committing
- The `shelly` label on GitHub issues triggers automated processing

## Shelly automation pipeline

This repo is serviced by **Shelly**, an autonomous agent dispatcher. When issues are labeled `shelly`, they flow through: tidy → delegate → test → commit → push → notify.
